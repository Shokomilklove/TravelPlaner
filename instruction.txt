*Create the Kubernetes Secret* #hand solution only for local build
The application uses an external Kubernetes Secret.
The Secret name is:
trip-service-secrets
Create it:
kubectl create secret generic trip-service-secrets `
  -n travel-planner `
  --from-literal=POSTGRES_USER=travel `
  --from-literal=POSTGRES_PASSWORD='YOUR_DATABASE_PASSWORD' `
  --from-literal=POSTGRES_DB=travel `
  --from-literal=SECRET_KEY='YOUR_SECRET_KEY' `
  --from-literal=JWT_SECRET_KEY='YOUR_JWT_SECRET' `
  --from-literal=INTERNAL_API_TOKEN='YOUR_INTERNAL_TOKEN'
Replace the placeholder values with your actual local values.

*Create DATABASE_UR*
Get the Secret:
$secret = kubectl get secret trip-service-secrets `
  -n travel-planner `
  -o json | ConvertFrom-Json
Read the required values:
$user = [Text.Encoding]::UTF8.GetString(
    [Convert]::FromBase64String($secret.data.POSTGRES_USER)
)
$password = [Text.Encoding]::UTF8.GetString(
    [Convert]::FromBase64String($secret.data.POSTGRES_PASSWORD)
)
$db = [Text.Encoding]::UTF8.GetString(
    [Convert]::FromBase64String($secret.data.POSTGRES_DB)
)
Build the connection string:
$url = "postgresql+psycopg2://{0}:{1}@postgres:5432/{2}" -f `
    [uri]::EscapeDataString($user),
    [uri]::EscapeDataString($password),
    [uri]::EscapeDataString($db)
Encode it:

$encoded = [Convert]::ToBase64String(
    [Text.Encoding]::UTF8.GetBytes($url)
)

Patch the Secret:
kubectl patch secret trip-service-secrets `
  -n travel-planner `
  --type merge `
  -p (@{
      data = @{
          DATABASE_URL = $encoded
      }
  } | ConvertTo-Json -Compress)
Check the Secret again:
kubectl get secret trip-service-secrets -n travel-planner
